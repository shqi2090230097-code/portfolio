# 首页参考复刻：实现与替换接口

## 参考范围

分析素材为用户提供的 19.27 秒录屏，分辨率 1012 × 570。逐段检查默认状态、约 2.4 秒和 13 秒的展开、单卡悬停、移出收回。约 15 秒后的变暗与重播图标，以及字幕、倍速菜单，属于视频播放器，不属于网站 UI。

录屏只展示一个桌面首屏，未展示导航、滚动后的页面、移动版和首次加载。因此首页使用独立的全屏构图，不强加旧首页的 Hero/Featured/Recent 列表或导航条。文件夹箭头进入 `/work`；其余路由继续保留全局导航和已有内容模块。轻微入场、移动端适配及 reduced-motion 是未展示状态的保守实现，不是从录屏读取的精确源参数。

## 对照参数

在 1012 × 570 视口，场景画布为 1012 × 558、上下居中：

- 默认文件夹前面约 294 × 168，位于 x≈359、y≈269。
- 展开后文件夹前面约 279 × 159，位于 x≈367、y≈295。
- 六个卡位的左右顺序和层级独立设置，中间主卡在前，侧面卡片被遮挡。
- 主要旋转角约 -18、-9、-2、4、11、14 度；卡片展开位移、闭合露出量和尺寸分别校准。
- 展开 transition 620ms、错峰 0–70ms，单卡悬停 360ms。使用带轻微超调的 cubic-bezier 近似录屏 spring 感。
- 鼠标移入展开、移出约 90ms 后收回；单卡上抬并提高层级。主体 pointer movement 仅作约 1–2 度的小幅倾斜。

参数均在 `src/design/tokens.mjs`：通用 token、响应式 token、fanSlots、interaction。组件与 CSS 不决定作品发布时间、featured 或分类。

## 内容与展示分离

`FolderPortfolio` 只从 getPublishedWorks 读取内容，先 featured，再按原有日期排序补最近作品，最多六件。中间主卡对应第一件，中央另一张对应第二件，再向两侧填充。每个真实卡片直接链接原详情路由。

目前作品只有两件且没有真实封面：两张可点击卡片对应现有内容，另四张只保留装饰卡位，不伪造作品和链接。所有无封面区域使用取自参考画面色块分布的简单占位，没有生成品牌图案。原作品文件和 Content Schema 未修改。

## 后续替换素材

- `src/data/home.ts`：背景单词、文件夹显示名称、两个贴纸的 src/alt。
- 贴纸坐标、大小、旋转及层级由 token 控制，替换透明 PNG/WebP 后不必重排文件夹。
- 作品封面继续在原作品 cover 字段指定。文件放原作品目录，仍走仅 published 的 `/media` 输出。
- 背景手写字暂用本地 Pacifico 字体与 CSS 高光/阴影近似。并非参考站的原始立体字素材。
- 字体文件取自 [Google Fonts / Pacifico](https://github.com/google/fonts/tree/main/ofl/pacifico)，OFL 许可随文件保存在 `public/fonts/`，不依赖访问者连接外部字体服务。
- 若之后提供原始背景字透明图、准确字体、贴纸和封面，可在展示层替换；不会要求修改项目正文。

## 交互与适配

- Desktop：移入展开，移出收回，悬停卡片抬高；箭头去全部作品。
- 窄屏/触屏：点击文件夹切换展开；点击空白收回，箭头和真实作品链接仍可用。展开距离缩短，保留中央构图。
- Keyboard：按钮 Enter/Space 展开，真实卡片可以获得焦点；Escape 收回并回到按钮。
- prefers-reduced-motion：关闭浮动和 transition，保留即时开合。
- 无脚本：箭头仍可进入 `/work` 浏览全部公开作品。

## 已知素材差异

缺少原始作品图、贴纸和背景立体字，因此当前只能校准其尺寸与层级，不能声称逐像素一致。CSS 玻璃材质和字体高光不同于原站可能使用的图像/3D 材质。录屏未给出源 easing、移动端或滚动状态，相应细节为按已观察行为的近似适配。

修改后应验证默认/展开/悬停/收回、键盘与窄屏点击，以及 Home/Work/两类详情路由和 draft/private 发布边界。不要把参考视频帧直接用作页面背景来掩盖交互差异。

## 续作校准（2026-09-09）

保留现有内容选择与六卡槽实现。对照展开帧将左右外围四张卡上移 1cqw，修正它们与前层文件夹的露出比例。修复手机舞台受 aspect-ratio 与 Grid 自动最小宽度影响而超出屏幕的问题：Grid 使用 minmax(0, 1fr)，舞台显式允许收缩。鼠标重新进入时恢复鼠标模式，避免键盘 Escape 后影响移出收起。
